# Thailand 2027 – Reiseseite

Eigenständige Version der Reiseplanung: Karte, Entdecken, Tage, Infos, Flüge, Hotels, Parken sowie Pack- und Checkliste.
Läuft ohne Claude und nach dem ersten Öffnen auch ohne Internet.

**Achtung: öffentlich.** Alles in diesem Repository kann jeder sehen. Keine Pass-, Karten- oder Buchungsnummern,
Tickets oder Kosten hier ablegen. Der Zugangscode beim Öffnen ist nur ein Sichtschutz.

## Aufs iPhone
1. Seite in Safari öffnen und den Code eingeben.
2. Teilen-Symbol → «Zum Home-Bildschirm».
3. Danach startet sie wie eine App und funktioniert auch offline.

Häkchen in Pack- und Checkliste und bei den Trainings bleiben nur auf dem jeweiligen Gerät gespeichert.
